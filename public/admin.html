กำหนดภาคเรียนที่เปิดรับแผนการสอน

เปิดหรือปิดรับแผนการสอนรายภาคเรียน ครูจะส่งแผนได้เฉพาะภาคเรียนที่เปิด (Active) เท่านั้น
รหัสภาคเรียน ชื่อภาคเรียน สถานะการเปิดรับแผน ช่วงเวลา การดำเนินการ

ยอดการส่งแผนการสอนแยกตามกลุ่มสาระการเรียนรู้

สรุปผลการส่งแผนการสอนรายกลุ่มสาระฯ พร้อมสัดส่วนการอนุมัติและรอพิจารณา
กลุ่มสาระการเรียนรู้ ส่งทั้งหมด อนุมัติแล้ว รอตรวจ ความคืบหน้า

กลุ่มสาระการเรียนรู้และหัวหน้าหมวดวิชา

บริหารจัดการกลุ่มสาระหลัก 8 กลุ่มสาระ พร้อมแต่งตั้ง/เปลี่ยนตัวหัวหน้ากลุ่มสาระฯ และเพิ่มหมวดวิชาใหม่ได้ตลอดเวลา
รหัสหมวด ชื่อกลุ่มสาระการเรียนรู้ / หมวดวิชา หัวหน้ากลุ่มสาระฯ (ผู้ตรวจประจำหมวด) อีเมลโรงเรียน (School Gmail) รหัส PIN ผู้ตรวจ จำนวนแผน / ครู การจัดการ

เครื่องมือผู้ดูแลระบบและตรวจสอบความสมบูรณ์

เครื่องมือวินิจฉัยความสมบูรณ์ของระบบไทม์ไลน์ 5 ขั้นตอน การสำรองและตรวจสอบความปลอดภัย

ตรวจสอบไทม์ไลน์ 5 ระดับ

สแกนและตรวจสอบแผนการสอนทั้งหมดในระบบ เพื่อรับประกันว่าทุกแผนมีขั้นตอนการตรวจ 5 ระดับครบถ้วนสมบูรณ์

รีเซ็ต PIN ตัวอย่าง (1234)

ตั้งค่ารหัส PIN ของผู้ตรวจทุกตำแหน่งให้เป็น 1234 สำหรับการทดสอบระบบหรือเมื่อต้องการเริ่มต้นรหัสใหม่

ระบบส่ง/ตรวจแผนการสอน

ไปยังหน้าตรวจแผนหลักและพอร์ทัลส่งแผนการสอน เพื่อดูมุมมองของครูผู้สอนและกรรมการผู้ตรวจ

วิธีเชื่อมต่อ Google Drive ของโรงเรียน (Google Cloud Service Account)
  1. สร้าง Google Cloud Project และเปิดใช้งาน Google Drive API
  2. สร้าง Service Account และดาวน์โหลดไฟล์คีย์ JSON นำมาวางไว้ที่ credentials/service-account.json
  3. สร้างโฟลเดอร์หลักใน Google Drive เช่น "แผนการสอน โรงเรียนสระหลวงพิทยาคม" แล้วแชร์โฟลเดอร์นั้นให้แก่อีเมล Service Account ด้วยสิทธิ์ "Editor (ผู้แก้ไข)"
  4. คัดลอก Folder ID มาใส่ในไฟล์ .env (ตัวแปร GOOGLE_DRIVE_FOLDER_ID) แล้วรีสตาร์ทระบบ

แผนผังโฟลเดอร์จัดเก็บเอกสาร (หมวดวิชา > ครูผู้สอน)

คลิกปุ่ม "ซิงค์/สร้างโฟลเดอร์บน Google Drive ทันที" ด้านบนเพื่อตรวจสอบและสร้างโครงสร้างโฟลเดอร์ของทุกหมวดและครูทุกคน
